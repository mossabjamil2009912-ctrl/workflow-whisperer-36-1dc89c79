# التقارير بدون «اختر المنظومة» + أزرار البوت بعد PVsyst

## 1) شاشة التقارير في لوحة الإدارة
- حذف قائمة «اختر المنظومة» من كل طلب.
- كل طلب يأتي جاهزاً بالتقرير المناسب لمنظومة العميل تلقائياً (حسب الإنفرتر والألواح والبطاريات في الطلب، ويُختار أقرب ملف مرفوع من «ملفات المنظومات»).
- داخل بطاقة الطلب فقط:
  - **فتح التقرير**: يعرض الملف.
  - **تعديل**: ترفع النسخة المعدّلة لهذا العميل؛ تُحفظ لهذا الطلب فقط ولا تغيّر ملف المنظومة الأصلي.
  - **إرسال للعميل**: يرسل النسخة المحفوظة (المعدّلة إن وُجدت) على واتساب.
- إذا لم يوجد ملف مناسب تظهر رسالة «ارفع تقرير لهذا الطلب» مع زر رفع داخل البطاقة نفسها.

## 2) البوت بعد العرض الرسمي
- الأزرار تصبح ثلاثة: **متابعة الشراء / طلب دراسة PVsyst / طلب مخطط SLD** (بدل زر «PVsyst / SLD» ثم خطوة اختيار).
- عند «طلب دراسة PVsyst»: يُسجَّل الطلب ويرسل الرسالة الحالية نفسها
  «دراسة PVsyst — تم تسجيل الطلب ... خلال دقائق» مع زرين: **متابعة الشراء / طلب مخطط SLD**.
- لا تُرسل رسالة المخطط تلقائياً بعد PVsyst.
- عند «طلب مخطط SLD»: يُسجَّل الطلب برسالة مماثلة مع زرين: **متابعة الشراء / طلب دراسة PVsyst** (إن لم يطلبها بعد).

## تفاصيل تقنية
- قاعدة البيانات: أعمدة جديدة في `report_requests` (`file_path`, `file_name`) لنسخة الطلب الخاصة.
- `crm.functions.ts`: مطابقة تلقائية للملف (من `report-rules.ts`/`bot-presets`) + `uploadRequestReport` + `openRequestReport`؛ `sendReportRequest` يرسل نسخة الطلب إن وُجدت وإلا الملف المطابق.
- `Reports.tsx`: إزالة الـselect وإضافة زر «تعديل» (رفع) في البطاقة.
- n8n State Machine: تعديل أزرار `qnext_ask/com_quote_ask/agr_quote_ask`، ومعالجة `aq_study`/`aq_sld` مباشرة بخطوة متابعة جديدة بزرين بدل `sld_ask`.
- اختبار للمطابقة التلقائية.
