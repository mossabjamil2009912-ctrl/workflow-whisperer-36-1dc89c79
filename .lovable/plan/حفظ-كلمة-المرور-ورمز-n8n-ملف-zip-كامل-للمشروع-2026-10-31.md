# حفظ كلمة المرور ورمز n8n + ملف ZIP كامل للمشروع

## 1. حفظ القيم بأمان داخل المشروع
- **كلمة مرور لوحة التحكم** → تُحفظ كمفتاح سري في المشروع (DASHBOARD_PASSWORD). التطبيق يقرأها منه أصلاً.
- **رمز n8n** و**رابط n8n** → يُحفظان كمفتاحين سريين (N8N_API_TOKEN و N8N_BASE_URL).
- لن تُكتب داخل ملفات الكود: لو رُفع المشروع إلى GitHub أو تسرّب، أي شخص سيقدر يدخل لوحة التحكم ويتحكم بالبوت. المفاتيح السرية تبقى محفوظة مع المشروع وتنتقل معه.
- إزالة رمز n8n القديم المكتوب في README.

## 2. ملف ZIP كامل
ملف واحد في «الملفات» يحتوي:
- كود التطبيق كاملاً (بدون مجلدات التثبيت والبناء المؤقتة).
- كتالوجات الأصناف PDF (30 ملفاً)، بيانات العملاء والمحادثات والأصناف (CSV).
- نسخة من سير عمل بوت n8n (ACTES WhatsApp Bot v35) كملف JSON لإعادة استيراده.
- تعليمات تشغيل مختصرة (README) بأسماء المفاتيح السرية المطلوبة — بدون قيمها.

## ملاحظة أمان
الملف يحتوي أرقام وهواتف ومحادثات العملاء، احتفظ به في مكان خاص. كلمة المرور والرمز لن يوضعا داخل الملف للسبب نفسه.
